# Fortunas-Rad

Ein farbenfrohes, vollständig statisches Zufallstool — ohne Anmeldung, externe Dienste oder Abhängigkeiten.

## Modi

- **Glücksrad:** Einträge eintragen und eine zufällige Person ziehen.
- **Paare bilden:** Namen mischen und zufällige Paare bilden; bei einer ungeraden Anzahl gibt es ein Freilos.
- **Teams bilden:** Namen gleichmäßig auf Teams verteilen und die gewünschte Teamgröße einstellen.

Listen lassen sich als UTF-8-Textdatei (.txt) speichern und wieder laden. Die Eingaben und Einstellungen werden automatisch lokal im Browser gespeichert. Drehdauer, Tempo, Soundeffekte und das Entfernen des Gewinners lassen sich einstellen.

## Lokal öffnen

Einfach index.html in einem aktuellen Browser öffnen. Für die Veröffentlichung auf GitHub Pages sind keine weiteren Schritte im Projekt nötig.

## Datenschutz

Das Projekt lädt keine externen Schriften, Bilder oder Skripte. Listen und Einstellungen verlassen den Browser nicht.
